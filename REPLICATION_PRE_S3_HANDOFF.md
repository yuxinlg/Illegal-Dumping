# Illegal-Dumping replication: BSTPP pre-S3 handoff

This branch is an explicitly provisional adaptation of the replication
analysis for the pre-S3 BSTPP coworker preview. It is intended for early model
construction and fitting tests only. Regenerate any scientific results after
the official S3 analysis-resumption boundary.

## What changed

- `replication/03_analysis.py` now uses the public `bstpp.main.Hawkes_Model`
  instead of the retired, untracked `bstpp.cox_hawkes_shared` module.
- The historical coefficient reference distribution is preserved explicitly:
  all active covariates are standardized with unweighted population moments
  over all 1,338 supplied CBG rows before any park or district clipping, and
  the model receives `standardize_cov=None`.
- Hawkes cutoffs are now real units: 100 days temporally and a fixed 1,000 m
  per-axis spatial window. The spatial variance prior uses provisional physical
  scale candidates of 50, 100, and 250 m, with 250 m as the default.
- The constructor now declares `cox_background=True`, rectangle excitation
  support, report-mode data contracts, and explicit beta/gamma/spatial priors.
- Code and data roots are separate. `BSTPP_PREVIEW_ROOT` selects the BSTPP
  checkout; `BSTPP_ANALYSIS_ROOT` selects the selective Illegal-Dumping clone.
- Core inputs are checked before fitting. `03a_analysis_by_division.py` inherits
  the same paths, cutoff units, prior scale, and standardization behavior.
- Each `03_analysis.py` figure directory receives `run_config.json` containing
  the package path, event/pair counts, windows, prior choice, covariate names,
  and standardization moments. Division summaries record the same key choices.
- The default `03_analysis.py` mode is the named-park replication described by
  the repository README. The confirmed 18-district boundary file is installed
  locally, so district mode and `03a` are also runnable.

## Running the park replication

Use the pinned `illegal-dumping` environment and check out both preview
branches. In PowerShell:

```powershell
conda activate illegal-dumping
$env:BSTPP_PREVIEW_ROOT = 'C:\path\to\BSTPP-cbg-preview'
$env:BSTPP_ANALYSIS_ROOT = 'C:\path\to\BSTPP_analysis'
python replication\03_analysis.py
```

The script prints `bstpp.__file__`; stop if it is not inside the intended
preview checkout. The committed default is named-park mode with
`PARK_NAME="cobbscreek"`. Change only `PARK_NAME` to run another available
park box. Set `PLOT_ROAD_NETWORK=False` when live OSM downloads are unwanted.

Before interpreting spatial-trigger results, rerun with each value in
`SPATIAL_SIGMA_SENSITIVITY_M = (50.0, 100.0, 250.0)` and retain the generated
`run_config.json`. The 1,000 m cutoff is a square eligibility rule: both
`abs(dx)` and `abs(dy)` must be at most 1,000 m, so diagonal separation can
reach about 1,414 m.

## District and neighborhood modes

The current local selective clone is ready for district fitting:

```powershell
python replication\03a_analysis_by_division.py
```

That command fits all 18 districts and is expensive. For an initial test, set
`UNIT_SUBSET = ["Lower South"]` in `03a_analysis_by_division.py`, then restore
`UNIT_SUBSET = None` for the full run.

For a fresh coworker clone, transfer the confirmed file separately to
`data/Planning_Districts.geojson` and verify the SHA-256 above. Alternatively,
set `BSTPP_PLANNING_DISTRICTS_PATH` to its location. The boundary file must
contain the `dist_name` column. Neighborhood density mode does not fit BSTPP
and its required neighborhood GeoJSON is present.

## Verification completed

- Both edited Python files compile under the pinned environment.
- The park-mode preflight finds all four core model inputs.
- District-mode preflight finds the installed 18-feature boundary file without
  an environment override.
- A real `03a` construction check succeeds for Lower South without an override:
  223 events and 6,295 eligible Hawkes pairs.
- Real Cobbs Creek construction succeeds at all three provisional prior scales
  (50, 100, and 250 m): 56 events, 1,540 eligible Hawkes pairs, 1,338
  standardization rows, a 100-day temporal cutoff, and a 1,000 m spatial cutoff.
- A five-step, 20-draw SVI plumbing run at 250 m completed with finite loss
  (`8.0721`). No long fit or posterior simulation was run; this should not be
  interpreted as a replication estimate.

## Deliberately out of scope

The corrected-Hawkes scripts under `replication/05*` still depend on
`cox_hawkes_offset.py`, which in turn copies and subclasses the retired shared
model implementation. They require a separate scientific migration and are
not made compatible by this analysis-only preview.
